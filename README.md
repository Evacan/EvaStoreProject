# Eva Tech Store

Eva Tech Store is a Node.js and Express e-commerce backend application connected to MongoDB Atlas.

## Features

- CRUD operations
- MongoDB Atlas integration
- REST API endpoints
- /getAll endpoint
- Jest automated testing
- automate.js sequential endpoint testing
- Frontend product display

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Jest
- Axios
- Render

## Endpoints

GET /products  
GET /products/:productId  
POST /products  
PUT /products/:id  
DELETE /products/:id  
GET /getAll
