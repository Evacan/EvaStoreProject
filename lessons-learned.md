# Lessons Learned

During this project, I learned how to build a full-stack Node.js and Express application connected to MongoDB Atlas.

I learned how to:
- Create REST API endpoints
- Perform CRUD operations
- Connect MongoDB Atlas to a Node.js application
- Use Mongoose models and schemas
- Create automated tests using Jest
- Deploy applications using Render
- Push projects to GitHub
- Create frontend pages connected to backend APIs

One of the biggest challenges was configuring MongoDB Atlas and deployment settings correctly. I also learned how environment variables work and why they are important for security.

Another important lesson was debugging server and deployment errors. I learned how to read logs, troubleshoot connection issues, and fix deployment problems step by step.

This project improved my understanding of backend development, deployment, API testing, and frontend integration.
